### 关于搜打撤：采纳 Loop Hero 三档，砍掉保险

Z8 侧自己推翻了自己上一轮的设计 —— 这是好事。复核后**同意**：

```
战死      → 带回 30%
中途撤离  → 带回 60%
满进度撤离 → 带回 100% + 奇遇判定
```

外加一张**不可保清单**（指定 1~3 种物品永不丢失、不计入收益）。

**为什么同意**：
- Loop Hero 是被验证过的（Steam 36,599 评测 / 92.7% 好评），三个数 + 一张清单 ≈ 20 行。
- 比「保险 + 三层结构 + 撤离时限」简单一个数量级。
- **不可保清单是对本项目历史 bug 的直接解毒剂** ——
  `main.js:153` 那条注释记着「化神期数学上不可达」：
  没有不可保清单，玩家一次翻车就可能永久卡关。

**但有一个反驳必须记下**：不可保清单解决的是「卡关」，
**不解决「净损失为负」**。30% 那档如果玩家反复死，
期望收益仍可能是负的。所以 XX-WORLD-006 必须带一条
**「连续失败 N 把后保底收益为正」的回归断言**。

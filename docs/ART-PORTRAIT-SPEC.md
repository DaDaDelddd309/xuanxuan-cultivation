# 立绘风格规格（量化版）

> 这份不是拍脑袋写的形容词，是**从仓库现有 10 张立绘采样出来的**。
> 采样脚本：`tools/art/measure_style.py`（改图后重跑，数字会变，规格跟着变）
> 采样时间：2026-10-09

## 一、量化参数

| 指标 | 实测值 | 含义 |
|---|---|---|
| 平均亮度 | 185–229（8/10 张） | **浅底**，不是暗底 |
| 暗部占比（L<32） | 0–5% | 几乎没有纯黑，只在轮廓线 |
| 中间调占比（32≤L<200） | 15–44% | 主体 |
| 暖调占比（R≈G≈B 且 L≥32） | **93–100%** | 几乎全是中性暖灰 |
| 饱和像素占比（S>0.45） | **0.0–0.2%** | **近乎无彩色** |
| 平均饱和度 | 0.07–0.14 | 极低 |
| 对比度（亮度标准差） | 33–68 | 柔和，不刺眼 |
| P5 / P95 亮度 | 33–151 / 231–251 | 墨线很黑，但纸白很亮 |
| 平均 RGB | (204,194,179) ~ (235,227,218) | 暖米白 |
| 色相中位数 | 32–37° | 橙黄区（暖），**无冷色** |

## 二、关键结论（我错过的地方）

1. **立绘是浅底，插画才是暗底。** `css/palette.css` 头部注释里
   「#000000 28.4% · #101010 15.4%」是**从 12 张插画**反推的，
   **不适用于立绘**。第一次生成反派时我照搬了那段，写成「暗底 87% 深灰」，
   结果整批图发闷发糊，和游戏现有 10 张完全不是一套东西。

2. **游戏本体是像素暗底，立绘是宣纸浅底。** 两者是**有意区分**的
   （局内 vs 局外），不是不一致。

3. **饱和度必须压到 0.2% 以下。** 任何红唇、绿叶、蓝天都会立刻出戏。

## 三、固定提示词模板

```
{prompt} 主体描述

STYLE (必须严格遵守,以下为实测参数):
- 背景:宣纸浅米白,平涂无渐变,带极淡纸纹
- 整体亮度:高(浅底),暗部只用于轮廓线
- 色彩:近乎无彩 —— 饱和度低于 0.2%,只用中性暖灰阶
- 色相:全部落在 30-40°(橙黄暖区),禁止蓝/绿/紫
- 高光:纸白 #ece5d3;暗部:墨黑 #1a1512
- 质感:水墨淡彩,笔触柔和,低对比(不要硬边高反差)
- 风格:唯美,东方古典,留白多,气韵生动
- 禁止:任何文字/字母/水印/签名/边框/分割线
```

## 四、角色卡规格（漫剧标准）

单张半身像不够。每个角色要出**角色卡**，包含：

| 类别 | 内容 | 数量 |
|---|---|---|
| 视角 | 正面 / 四分之三侧 / 正侧 / 背面 | 4 |
| 表情 | 平静 / 冷厉 / 愤怒 / 负伤 | 4 |
| 全身 | 站姿全身（含服装细节） | 1 |

用途：
- 回合制的多视角（侧身出场、转身离场）
- 对话时的表情切换
- 图鉴的立绘展示

**当前状态**：仓库里 10 张立绘**全是单张半身像**，没有任何多视角或表情变化。
这是「5 毛钱特效立绘」的根源 —— 不是画得差，是**规格就只有一张**。

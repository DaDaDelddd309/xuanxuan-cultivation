## 一、问题

旧版「贴边」交互 = **45 秒计时器 + 4 个固定按钮 + 加两个数值**：

```
range: +8 ~ +18
spd:   +0.05 ~ +0.12
aff:   两个选项 +2/+3，两个 +0
```

选哪个都不改变任何操作方式。台词从固定池随机抽，台词再好也只是换皮。

**核心错误**：把角色放在**没有"行为"的层**（修仙阁菜单）里，用弹窗假装情感。
菜单层只有点击，没有行为。

---

## 二、决策：删掉重做

这是割草游戏。割草游戏的情感语言是**动作**，不是菜单。
角色必须活在有行为的层（砍杀局内）里，情感自然产生。

---

## 三、新设计：她是局内的一个真实存在

### 局内行为

| 行为 | 实现 | 数值 |
|---|---|---|
| **捡东西** | 场上跑，把宝石捡走。你**看得见**她捡 | 每局 5–12 颗 |
| **会受伤** | 怪打她她也掉血 | 生命 60，被打 -10 |
| **会躲** | 你血量 <30% 时她后退，不挡在你前面 | — |
| **会不在** | 连续死 3 次，这一局不出场 | — |

### 她说什么：由你这一局的表现决定

**不给选项。** 每局最多 2 句，事件触发。

| 触发条件 | 她说 |
|---|---|
| 满血通关 | 「今天没出手。」 |
| 死了一次 | 「你上次差点没回来。」 |
| 死三次 | 这一局她不出场 |
| 连续三局没死 | 她第一次问你名字 |
| 用了闪屏/被动保命 | 「你越来越会躲了。」 |

**这是你打得好不好的镜子，不是选项。**

### 修仙阁里

**什么都不做。**

- 不进人物页
- 不弹气泡
- 不给任务
- 想看就看一眼，她不说话

唯一保留：**年表记一笔** —— 你死在哪、她在不在、捡了多少。
时间痕迹，不是养成任务。

## 四、删掉了什么

`companion.js` 里：

- `hug()` / `hugChoose()` / `HUG_CHOICES` / `HUG_LINES`
- `addAff()` / `s.aff`（亲密度）
- 三条路线 `kiss` / `cold` / `ghost` 的选择逻辑
- `cold()` / `ghostLine()` / `COLD_LINES` / `POSSESS_LINES` / `FLASH_LINES`
- `tryGift()`（随机送礼）

保留：名字、怨灵附身（玩法机制不是情感系统）、局内拾取、篝火守望。

**342 行 → 230 行。**

---

## 五、顺带解决的

灵伴在局内**真的做事**（捡东西、会受伤），
两个系统之间就有了真实连接 —— 不是"局末折算道行"那种数值交换，
是**一个你看得见的角色在替你干活**。

## 七、验收标准

1. 砍杀时能**看见她**在场上捡宝石 ✓
2. 怪能打中她，她会消失一段时间 ✓
3. 她的台词**和你这局的表现相关**，不是随机 ✓
4. 修仙阁里她**不弹任何东西** ✓
5. 一局之内因她产生的打扰次数 = 0（除了事件台词 ≤2）✓

## 一、为什么改，以及改掉什么

V1 的问题不是执行不到位，是**方向本身**：

| V1 的困境 | owner 原话 |
|---|---|
| 「水墨淡彩」饱和度低于 0.2%、只留轮廓线 | 「立绘也不够可爱」 |
| 「不是 Q 版商业手游」被写进规范当铁律 | 想要的正是手游/二次元那种**讨喜**的观感 |

**注意**：V1 那套「近乎无彩」的约束，恰恰**主动排斥**了「可爱」的视觉要素
（大眼高光、腮红、暖肤色、糖果色高光）。所以不是执行没到位，是**规范在压制可爱**。

### 保留的技术护栏（这些不是审美，是工程约束）

- **720×964**（`art-reach` 实测所有现有立绘都是这个尺寸）
- **禁水印 / 禁文字 / 禁边框 / 禁签名**
- **暗色剪影 + 金线 `#c9a227`** 作为强调色（`PALETTE.md` 指定，全局唯一亮点）
- 需落在 `tools/art/measure_style.py` 的实测调色板区间内（CI 会卡）

## 二、风格内核（V2 新增）

```
STYLE (2026-10-10 V2 —— 现代手游/二次元可爱风):

画风基准
- 现代日式二次元手游立绘,不是水墨,不是像素,不是 Q 版贴纸
- 造型:头身比约 1:2.5 的可爱比例(不是写实 1:7)
- 眼睛:大而圆,占脸宽约 1/3,**必须有高光点**(至少两颗:主高光 + 下方弱反光)
- 表情:柔和上扬,嘴角微翘;腮红明显(这是「可爱」的第一要素)
- 皮肤:暖白偏粉,柔和渐变,**允许腮红与唇色**(V1 禁止,V2 明确允许)

配色
- 主色板:奶油白 / 蜜桃粉 / 浅金 / 天青 —— 高明度、中低饱和
- 饱和度:V1 要求 <0.2%,V2 放宽到 **12%~28%**(可爱需要色彩,但不要艳俗)
- 强调色:金色 #c9a227 用于发饰/衣边/眼神光(全局唯一亮色,不滥用)
- **禁止**:纯黑描边(V1 允许,V2 改用深棕 #4a3a33 软描边)、荧光色、大面积纯白高光
- 禁止:赛博/暗黑/哥特/写实摄影风

质感
- 赛璐璐上色(cel shading):两到三阶明暗,**硬边色块**,不要水墨笔触
- 高光:额头/鼻尖/肩膀一处柔和的哑光高光
- 边缘:干净的细描边 + 轻微外发光(让角色从背景里「浮」出来)

背景
- 与立绘主体**强对比**,让角色一眼分离:
  选项 A(推荐):径向渐变暖光(中心 #fff8ee → 边缘 #e8d9c4)
  选项 B:纯色 #f6efe2 + 极淡光晕
- 禁止:复杂场景、道具、文字、水印

禁止项(硬性)
- 任何文字 / 字母 / 水印 / 签名 / 边框 / 分割线
- 多余的手指、扭曲的肢体、错位的耳朵
- 过度磨皮到失去五官边界
```

## 三、宝宝（开局灵伴）专用规格

这是 owner 点名要重做的角色。

```
{prompt} 一只可爱的东方修仙小灵伴,看起来是个 5-6 岁的小女孩,
Q 版三头身(约 1:2.5),圆圆的脸,超大而明亮的眼睛(占脸宽 1/3),
两颗清晰的白色高光点,腮红两坨明显的粉,小嘴微微上翘。

发色:浅金偏暖,发型为双丸子头 + 碎刘海,发梢微微翘起(动态感)。

服装:素白交领小衫 + 浅金滚边,衣料轻盈,整体不超过三色。
配色:奶油白为主,蜜桃粉点缀,金色滚边。

表情:闭眼微笑(刚睡醒的感觉),但眼睛要画完整 —— 
      若闭眼,眼睫毛必须画成好看的弧线,不能是一条线。

气质:呆萌、慵懒、有点迷糊,但**可爱**。不是仙气飘飘,不是高冷。

STYLE:严格遵守上面的 V2 STYLE 块(赛璐璐上色 / 暖白粉金配色 / 
      径向暖光背景 / 深棕软描边)。

禁止:写实、Q 版贴纸风、赛博、暗黑、水墨、任何文字水印。
```

## 五、出图后的验收（可执行）

```bash
# 1. 尺寸必须 720×964
node tests/asset-reach.mjs assets    # 会列出文件与大小

# 2. 调色板必须落在实测区间(CI 会卡)
python3 tools/art/measure_style.py

# 3. 立绘门禁(会检查 CAST 名单里的每个角色都有图)
node tests/lint-portraits.mjs

# 4. 资源可达性(确认新图真的被引用,不是又一张死资源)
node tests/asset-reach.mjs assets
```

**新增门槛（V2 专属）**：`measure_style.py` 的调色板区间原本是按**水墨**实测的。
换画风后必须**重跑一次基线**重新校准区间，否则新图会因「超出水墨区间」被卡。
这是本次改版最容易踩的坑。

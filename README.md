# 轩轩修仙传

> 大衍历四二七年,灵气渐衰。你原是无名散修,一场机缘让你得了残卷,自此踏上修行路。
> 这世界不讲道理,只讲生死与机缘。

一款纯前端的水墨修仙 RPG。以原版自动割草为核心玩法,叠加修仙家族养成层。

**在线游玩**:<https://dadadelddd309.github.io/xuanxuan-cultivation/>

---

## 玩法结构

游戏有**两层**,互不干扰:

### 第一层 · 砍杀(原版自动战斗)
进游戏即玩。移动、躲避、自动攻击、升级三选一。**这是主要的时间消耗。**

- 4 个可选角色(骑士/法师/游侠/白衣)
- 武器合成、图鉴、怪物图鉴
- 局外只保留金币与解锁角色

### 第二层 · 修仙阁(11 个标签页)
打通修仙资源、养成、家族、世界。所有内容在这里。

| 标签 | 作用 |
|---|---|
| **境界** | 炼气 1-12 层 → 筑基 → 金丹 → 元婴 → 化神。吐纳涨修为,突破耗丹药 |
| **大地图** | 11 个节点,迷雾探索。相邻移动,秘境界/妖巢触发回合制 |
| **营地** | 投源石生火。火在时怪物进不来,可挂机刷资源。火烧完自动结算 |
| **领地** | 6 格建造空间(幻境,无怪)。灵田/丹炉/哨塔/议事堂/演武场/灵井/集市 |
| **神通** | 14 门基础神通,两门满级可悟道融合出超武(10 种配方) |
| **行囊** | 源石、传承书、丹药、建材、灵米 |
| **家族** | 立族、繁衍、族人培养、全属性修士、领地攻防 |
| **人物** | 灵伴三形 + 剧情人物 + 行脚日记 |
| **称号** | 8 个,按行为触发(赤子之心/剑圣/入魔/赤水真人…) |
| **图鉴** | 传说妖谱(8 只) + 怪物图谱(8 种) |
| **存档** | 世界种子切换 + 存档码导出导入 |

## 三条开局路线

第一次进游戏会有一个仪式。**这个选择永久生效**,决定你身边是谁:

| 选择 | 她是谁 | 你得到什么 | 威胁 |
|---|---|---|---|
| **好呀** | 宝宝(灵伴) | 自动拾取掉落物(刻意不快,一次一个)。贴边时给你选项,选项提升拾取范围/速度。境界越高她越亲密 | 无 |
| **不要** | 鬼火 | 定期赠送道行/修为/源石。自说自话,**不给选项** | 低 |
| **谈恋爱会影响我修仙** | 怨灵 | …… | 高。她会附身怪物并大幅强化,每 5 次闪屏警告。打散后 2 分钟复活,并预告下一个宿主。**永远打不死。** |

怨灵路线在篝火状态下会在火**外**召唤强化妖物。火内(源石护栏)**绝对安全,永不被突破**。

## 世界在运转

不是随机抽事件,是**剧本推进**。5 条叙事线,每条 4 环,每环有线索、有揭示、两个结局。

你到了对应节点,那件事才会露头。世界上的**流言**会自己长出来,流浪商人和鬼火会念给你听——念过的不会重复。

**传说妖谱**里每只妖都有来历。比如红衣女鬼:她爹在大旱那年把她卖给黑山姥姥换粮,她死在第一年冬天,身上还穿着嫁衣。

昼夜四段(晨/昼/暮/夜)各有色调、雾浓度、音景。夜里怪物 ×1.65,清晨 ×0.82。**音效是 WebAudio 实时合成,项目不打包任何外部音频文件。**

## 技术栈

- **纯静态**,无后端、无构建步骤、无框架
- 原生 ES Modules,Canvas 2D 渲染
- Service Worker 离线可玩
- PWA(可添加到手机桌面)
- 存档在 localStorage(单一 profile 键 + 自动存档 + 存档码导出)

### 为什么不用框架

原版是一个 3 万行的 Canvas 游戏,引入框架意味着重写渲染层。所有修仙内容以**独立模块层**(`js/xiuxian/`)接入,通过事件总线和状态桥接,**不侵入** `js/game/`、`js/ui/` 的原有循环。

## 跑测试

```bash
bash tests/run-all.sh        # 逻辑测试 + 静态检查 (~510 项,秒级)
bash tests/run-browser.sh    # 浏览器全流程 (Playwright,较慢)
```

**部署前必跑两个。** 只跑逻辑测试不够 ——
V0.88 的「结局无限刷奖励」和 V0.89 的「修仙阁白屏」逻辑测试都是全绿的,
只有浏览器才炸得出来。原因见 [`AGENTS.md`](AGENTS.md) 第零点五节。

`run-all.sh` 除逻辑测试外还跑三个静态检查,
它们抓的是 `node --check` 抓不到的语义问题:

| 检查 | 抓什么 |
|---|---|
| `lint-imports.mjs` | 重复 import → ES module 加载失败,页面白屏且零报错 |
| `lint-precache.mjs` | sw.js 预缓存重复项 / 指向不存在的文件 → SW install 整体失败 |
| `lint-version.mjs` | 版本号在 4 处不一致 |
| `lint-methods.mjs` | 调用了 `this.xxx()` 但方法没定义 |
| `lint-testversion.mjs` | 测试里写死了版本号(每次升版都要改测试,漏改就假失败) |
